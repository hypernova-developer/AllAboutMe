# hypernova-developer | Anonymous Portfolio

This is the official, anonymous portfolio website for **hypernova-developer**. Designed with a focus on minimalism, cyber-aesthetics, and technical transparency.

## 🚀 Features
- **Anonymous Identity:** Focused purely on code and technical skills.
- **Dynamic Skill Bars:** Visual representation of proficiency in C++, Python, and Web technologies.
- **Interactive UI:** Custom-built mouse trail effect and smooth scroll navigation.
- **Responsive Design:** Optimized for various screen sizes.

## 🛠 Tech Stack
- **Languages:** HTML5, CSS3, JavaScript (ES6+)
- **Tools:** Fusion 360, Canva
- **Theming:** Deep space / Cyberpunk aesthetic

## 📂 Project Structure
- `index.html`: The core structure and semantic content.
- `style.css`: Custom styling, layout, and animations (No inline styles).
- `script.js`: Mouse interaction logic and dynamic UI elements.
